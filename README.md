# MARK — Adaptive Market Intelligence

**An ambitious AI-powered market research and prediction system.**

## About

MARK is an ongoing machine learning project aimed at building an adaptive market intelligence system that goes beyond traditional market prediction.

The goal is to develop a system that can analyze financial markets, make predictions, evaluate its own performance, investigate mistakes, generate new hypotheses, and improve through continuous research and experimentation.

Rather than simply predicting market movements, MARK aims to understand market behaviour and learn from evidence.

## Vision

The long-term vision of MARK is to build an intelligent system capable of:

- Analyzing financial market data.
- Predicting potential market movements.
- Evaluating predictions against actual outcomes.
- Investigating why predictions succeed or fail.
- Generating and testing new trading hypotheses.
- Discovering useful patterns and relationships in market data.
- Improving models through evidence-based experimentation.
- Maintaining knowledge from previous research.

## Core Idea

**Predict → Evaluate → Investigate → Experiment → Learn → Improve**

MARK is designed around the idea that a good prediction system should not only make predictions but also understand its mistakes and continuously search for better approaches.

## Initial Development

The project initially focuses on the NIFTY 50 market index using historical daily market data.

Current development includes:

- Historical market data collection.
- Data cleaning and preprocessing.
- Feature engineering.
- Machine learning model development.
- Time-based model validation.
